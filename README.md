# ミラン研究所 Ver.2.1.1

Ver.2.1の機能に加え、九九の音声読み上げを小学校の唱え方に修正しました。

- 「かける」「は」は読み上げません
- 例：1×1＝1 →「いんいちがいち」
- 例：2×2＝4 →「ににんがし」
- 例：8×8＝64 →「はっぱろくじゅうし」
- 日本語音声・少しゆっくりの速度で再生します

更新方法：このフォルダー内の6ファイルをGitHubリポジトリ直下へ上書きアップロードしてください。既存データは `miranLabDataV1` を継続使用するため、同じURLなら原則引き継がれます。更新前にアプリの「記録」からバックアップを書き出してください。
