# ミラン研究所 夏休み探究ノート PWA

## 主な機能
- 今日の3ミッションと研究ポイント
- 小学1〜3年向け簡易算数問題
- 探究ノート（写真添付対応）
- スケボー練習記録
- 気分・体調記録
- JSONバックアップ／復元
- 印刷・PDF保存
- オフライン利用（Service Worker）

## 起動方法
PWA機能は `file://` では動かないため、Webサーバーで公開してください。

### 手元で確認
このフォルダで以下を実行します。

```bash
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開きます。

## 公開方法
GitHub Pages、Netlify、Cloudflare Pages、Vercel等の静的ホスティングにフォルダ一式を配置できます。HTTPSで公開すると、対応ブラウザでホーム画面への追加ができます。
